# Політика безпеки

## Як повідомити про вразливість

**Не створюйте публічний issue.** Повідомляйте приватно через GitHub Security Advisories:

1. Відкрийте вкладку [Security → Advisories](https://github.com/grengojbo/keycrm-mcp-go/security/advisories/new) репозиторію.
2. Натисніть **Report a vulnerability** і опишіть проблему: версію, кроки відтворення, можливі наслідки.

Не додавайте до звіту справжні API-ключі, токени чи дані клієнтів.

## Що відбувається далі

- Підтвердження отримання — протягом 7 днів.
- Оцінка й план виправлення — протягом 30 днів; складні випадки обговорюємо в тому ж advisory.
- Після випуску виправлення advisory публікується, автора звіту згадуємо, якщо він не проти.

## Підтримувані версії

Виправлення безпеки виходять для останньої випущеної мінорної версії.

## Що вважаємо вразливістю

Зокрема:

- обхід `KEYCRM_READ_ONLY` чи обов'язкового `confirm: true` для інструментів запису;
- витік API-ключа, токена або персональних даних у логи чи результати;
- SSRF або читання файлів поза `KEYCRM_UPLOAD_DIR` під час завантаження файлів;
- обхід Bearer-автентифікації транспорту HTTP.
